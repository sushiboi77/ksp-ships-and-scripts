# KSP ships and scripts

Backup of my Kerbal Space Program craft and kOS scripts, copied on 2026-11-08.

## Contents

- `saves/AeroSpace/Ships/`: 9 craft files and their 9 `.loadmeta` files.
- `saves/SUSHIBOI/Ships/`: 40 craft files and their 40 `.loadmeta` files.
- `Ships/Script/`: 40 kOS `.ks` files, including the `boot/` folder.

The original folder layout and file contents are preserved. The game folders remain in place. Full save-state files, game binaries, mods, stock craft, and old diagnostic backups are outside this backup.

## Restore

Close KSP, back up the destination folders, and copy the folders above into the matching locations under your KSP installation. To use the craft in a different save, copy its `Ships/VAB/` and `Ships/SPH/` files into that save's corresponding folders.

Install kOS to use the scripts. The craft files identify KSP 1.12.5 and can require the same mods and parts used to build them; those dependencies are not included.
